## 2. Quy trình tra cứu tự xử lý 3 bước (Troubleshooting Process)
* Bước 1 - Googling: Copy chính xác dòng báo lỗi cuối cùng trong Terminal, kẹp thêm tên công nghệ và tìm trên Google.
* Bước 2 - Community Search: Chỉ ưu tiên các trang web cộng đồng (Stack Overflow, GitHub Issues), đọc các bình luận có nhiều Upvote hoặc Tích xanh.
* Bước 3 - AI Translation: Nhờ AI (ChatGPT/Gemini) đóng vai chuyên gia giải thích nguyên nhân và hướng dẫn cách sửa bằng tiếng Việt dựa trên giải pháp tìm được ở Bước 2.
